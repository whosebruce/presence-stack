## Important billing boundaries

1. A ChatGPT subscription is not general OpenAI API credit.
2. The $50 OpenRouter amount is a prepaid balance, not automatically $50 every month.
3. Buying $50 of OpenRouter credit currently costs $52.75 because the 5.5% fee is greater than the $0.80 minimum.
4. ChatGPT's interactive image creation does not automatically fund arbitrary image-generation API calls made by an agent.
5. Self-hosted does not mean free: electricity, backups, replacement disks, admin time, and internet exposure controls still exist.
6. BlueBubbles software is free, but a dedicated Mac and mobile line are not.

## Suggested budgets

### Lean private agent

- ChatGPT Plus: $20/month, or another provider.
- OpenRouter: $10–$25/month cap after a small initial deposit.
- Honcho: built-in Hermes memory first; managed Honcho budget $2–$10/month if needed.
- Self-hosted search: software $0; power included in server estimate.
- Messaging: Discord/Telegram $0; no BlueBubbles hardware purchase.

### Proposed Presence Stack

- ChatGPT Pro 5× tier: $100/month.
- OpenRouter: $50 initial credit purchase ($52.75 charged), then usage-based top-ups with a hard cap.
- Honcho: managed budget from measured ingestion/query use, or self-host with explicit compute/model cost.
- BlueBubbles: $0 software + existing always-on Mac; optional dedicated line.
- SearXNG/Firecrawl: local software + server power/maintenance.
- Optional domain, offsite backup, and VPS/Tailscale path.

### Heavy operator

Use ChatGPT Pro $200 only after the $100 tier's measured limits block real work. Increase OpenRouter/Honcho budgets from usage logs—not enthusiasm.

## Hardware planning ranges (not vendor quotes)

These are rough U.S. planning allowances, deliberately wide because each owner's hardware and goals are different:

| Item | Planning range |
|---|---:|
| Reuse existing server | $0 |
| RAM/boot-SSD refresh | $75–$200 |
| Two CMR media/NAS disks | $250–$600+ depending on capacity |
| Used Intel SFF/tower | $150–$450 |
| Low-power Intel mini PC | $150–$350, often excluding storage expansion |
| Used always-on Mac for BlueBubbles | $150–$500 |
| UPS | $100–$250 |
| Separate backup drive/target | $100–$500+ |

Do not buy hardware until the intake form identifies drive bays, SATA/HBA layout, RAM ceiling, iGPU, expected media capacity, and backup target.
